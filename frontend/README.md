YAIRS Frontend Dashboard

This is a Next.js + React + TypeScript dashboard for the YouTube AI Research System backend. It relies on the backend REST API exposed by the FastAPI application.

Environment

- NEXT_PUBLIC_API_BASE - Base URL of the backend API (e.g. http://localhost:8000)
- NEXT_PUBLIC_API_KEY - Optional API key header to include in requests

Commands

- npm install
- npm run dev
- npm run build
- npm run start

Notes

- Uses TailwindCSS and shadcn/ui primitives.
- This is a starter scaffold; components are modular and meant to be extended.
